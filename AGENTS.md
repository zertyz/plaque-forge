# Project instructions

Plaque Forge's canonical policies, requirements, and protected human-authority artifacts are stored in
`governance/` and defines project-wide rules that must be observed on each action.


## Mandatory preflight

Before designing, modifying, generating, formatting, or reviewing repository changes:

1. Read `governance/policies/governance.md` and honor completely, as well as evey other policy in that directory.

Do not infer policy from descriptive documentation when registered authority exists. Descriptive docs may explain current
mechanisms but cannot overrule governance.


## Engineering scope

Apply current policy fully to new and substantially modified code. Improve directly affected legacy code when reasonable,
but do not turn a focused task into unrelated repository-wide compliance work.
